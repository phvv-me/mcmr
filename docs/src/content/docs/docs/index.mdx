MCMR is a policy engine for whole repositories. A Rust kernel reads your source tree once into
typed tables, Python rules query those shared tables, and a rule that can offer a fix only keeps
it after MCMR proves the fix actually worked. These docs explain the pieces in the order you would
actually meet them, from a first `mcmr check .` to the DataHub metadata a scheduled run leaves
behind.

Read any page in a few minutes. When a page needs an idea it does not own, it links the page that
does instead of explaining it twice.
