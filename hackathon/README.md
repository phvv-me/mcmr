# Submission workspace

This directory keeps event-specific material outside the product README and documentation site.

- [SUBMISSION.md](SUBMISSION.md) contains the Devpost copy and submission checklist.
- [DEVPOST_ANSWERS.md](DEVPOST_ANSWERS.md) contains the final short-form narrative answers.
- [VIDEO_SCRIPT.md](VIDEO_SCRIPT.md) contains the recording narration and screen cues.
- `screenshots/` contains the current DataHub capture set.
- `thumbnail.jpg` is the visual reference used for the product banner and icon.

The current screenshots predate the run-status and platform-icon fixes. Recapture the Runs tab and
any screen that shows the platform mark after publishing the updated integration. Do not submit a
screen where a completed policy check appears as an operational failure.
